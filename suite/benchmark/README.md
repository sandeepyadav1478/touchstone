# `suite/benchmark` — benchmark v1

Ten cases, frozen. **`benchmark_hash` = `4c935f063e1353017d9cefe71f13d60ee97b0a22fcdd6cb1d90ba7417e187c2f`.**
Every row of the version table quotes it, and two rows that quote different hashes are not
comparable — that is the whole reason this tier is frozen and the regression tier is not
([D-024](../../docs/01-spec.md#the-two-tiers-d-024)).

Regenerate and check it with:

```bash
uv run pytest tests/unit/test_invariants.py -k frozen
```

⛔ **`truth.json` is loaded by the scorer and by nothing else.** No tool reads it, no prompt
quotes it, and `tests/unit/test_invariants.py` checks the serialised case files for every one of
the eleven class names rather than trusting that sentence.

**Four of the eight answerable cases name a service other than the one that paged.** Answering
with `alert.service` is the most common naive triage failure, so it is planted rather than
avoided ([docs/01](../../docs/01-spec.md) §2).

## ⚠️ What v1 does not measure

- **`config_drift` and `noisy_neighbor` are drawn but never scored as themselves.** They are the
  two mechanisms the deletion path consumes. A version could answer both classes wrongly in every
  case and this score would not move. Fixing it means an eleventh and twelfth case, which is a
  **benchmark version bump** that orphans every past score — so it waits for one.
- **`precedent` is absent.** It stratifies the memory experiment, which has no history corpus
  yet, and its *values* change when one arrives — writing `"none"` now would disguise the bump
  rather than avoid it ([docs/09](../../docs/09-schemas.md) §5).
- **n = 10.** Ten cases at k = 3 is thirty attempts, which is enough to refuse a regression and
  not enough to rank two versions that differ by one case. The version table says so in its own
  header rather than leaving the reader to work it out.

## Provenance

Generated by `src/touchstone/incidents/generate.py` from the seeds in `manifest.json`. The
generator takes its date as an argument and never reads a clock, so
`write_suite(BENCHMARK, added="2026-08-18")` reproduces these bytes exactly.

The shapes are drawn from four public sources that were **read and never loaded** — Loghub,
RCAEval, the OpenTelemetry demo, and danluu/post-mortems ([D-029](../../docs/01-spec.md#4-the-generator),
measurements in [docs/01](../../docs/01-spec.md) §4). Nothing from them is vendored, imported or
listed in `pyproject.toml`. The log level mix here — ≥90% `INFO` in every case, ≤3% `ERROR` — is
that read's main consequence, and it is asserted in the tests.
